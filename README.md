# 🐾 Pet AI Triage & First-Aid Assistant
### ระบบคัดกรองอาการและปฐมพยาบาลสัตว์เลี้ยงฉุกเฉินเบื้องต้นด้วย AI (สุนัขและแมว)
เชื่อมต่อกับ **AI for Thai (AIFT)** และ **Thai LLM**

---

## 📌 1. ที่มาและความสำคัญของโครงงาน (Problem Statement)
ในปัจจุบัน เจ้าของสัตว์เลี้ยง (Pet Parents) มักประสบปัญหาเมื่อสัตว์เลี้ยงเกิดอาการผิดปกติกะทันหัน เช่น:
- **เผลอกินสิ่งอันตราย**: เช่น แมวกินยาพาราเซตามอล (เป็นพิษต่อตับและเม็ดเลือดแดงอย่างรุนแรงถึงชีวิต), สุนัขกินช็อกโกแลต
- **ภาวะวิกฤตเฉียบพลัน**: เช่น แมวเพศผู้เบ่งฉี่ไม่ออก (ท่อปัสสาวะอุดตัน เสี่ยงไตวายและหัวใจหยุดเต้นภายใน 24 ชม.), ภาวะฮีทสโตรก (Heatstroke) จากอากาศร้อนจัด
- **การปฐมพยาบาลที่ผิดวิธี**: เช่น การเอาน้ำแข็งราดตัวสัตว์ที่เป็นฮีทสโตรก (ทำให้หลอดเลือดหดตัวจนช็อก), หรือการป้อนยาแก้ปวดของคน

**Pet AI Triage** พัฒนาขึ้นมาเพื่อแก้ไขปัญหานี้ โดยทำหน้าที่เป็น **"ด่านคัดกรองฉุกเฉินอัจฉริยะ"** ที่ช่วย:
1. ประเมินระดับความรุนแรงของอาการ (Triage Level: เขียว/เหลือง/แดง) ทันที
2. แนะนำขั้นตอนการปฐมพยาบาลที่ปลอดภัย (First-Aid Checklist)
3. เตือนข้อห้ามเด็ดขาด (Critical Don'ts) ป้องกันความผิดพลาดของเจ้าของ
4. ใช้ AI for Thai / Thai LLM วิเคราะห์อาการแบบภาษาธรรมชาติ และให้คำแนะนำที่สอดคล้องกับบริบทภาษาไทย

## 🌟 2. ฟีเจอร์เด่นของระบบ (Key Features)

- 🐶🐱 **รองรับทั้งสุนัขและแมว**: คัดกรองและปรับคำแนะนำตามสรีระเฉพาะของแต่ละชนิดสัตว์
- ⚡ **One-Click Demo Presets**: มีปุ่มทดสอบเคสวิกฤตยอดนิยม 4 แบบ (พาราเซตามอล, เบ่งฉี่ไม่ออก, ช็อกโกแลต, อาเจียน) เพื่อความสะดวกในการสาธิต
- 🚨 **Dynamic Risk Severity Badge**: แสดงระดับความเร่งด่วนแบบเรียลไทม์ พร้อมแถบไฟกระพริบเตือนสีแดงสำหรับเคสวิกฤต (Pulse Emergency Animation)
- 📋 **Structured Emergency Protocol**:
  - ขั้นตอนการปฐมพยาบาลที่ต้องทำทันที (Action Steps)
  - สิ่งที่ **ห้ามทำเด็ดขาด** (Critical Warnings)
  - สิ่งที่ต้องเตรียมนำไปโรงพยาบาล (What to bring)
- 🗣️ **Voice Assistant (Web Speech API)**: กดฟังเสียง AI อ่านคำแนะนำการปฐมพยาบาลให้ฟังขณะที่กำลังดูแลสัตว์เลี้ยง
- 🧠 **Hybrid Intelligence Architecture**:
  - รองรับการเชื่อมต่อกับ **AI for Thai (`aift.multimodal.textqa` / Thai LLM)**
  - มี **Offline Veterinary Triage Engine** เป็น Safety Fallback มั่นใจได้ว่าระบบทำงานได้ราบรื่น 100% แม้เน็ตหลุดหรือโควต้า API หมด

## 🛠️ 3. สถาปัตยกรรมระบบและเทคโนโลยี (System Architecture)

```
┌────────────────────────────────────────────────────────┐
│             Web UI (Tailwind CSS + HTML5)              │
│       - Interactive Chips / Demo Presets / Voice       │
└───────────────────────────▲────────────────────────────┘
                            │ HTTP POST /api/triage
                            ▼
┌────────────────────────────────────────────────────────┐
│              Python Standalone Server (app.py)         │
│               (Built-in Python HTTP Server)            │
├───────────────────────────┬────────────────────────────┤
│   AI for Thai API Layer   │    Offline Triage Engine   │
│ (aift.multimodal.textqa)  │ (Clinical Protocols / Rule)│
└───────────────────────────┴────────────────────────────┘
```

- **Frontend**: HTML5, Modern CSS (Tailwind CSS CDN), Vanilla JavaScript, Web Speech API
- **Backend**: Python 3.10+ (Standard Library `http.server`, `urllib`, `json`) — ไม่ต้องลง Framework ขนาดใหญ่ รันได้ทันที
- **AI Integration**: โมดูล `aift` (`aift.multimodal.textqa`) ของ NECTEC / AI for Thai

## 🚀 4. ขั้นตอนการติดตั้งและรันระบบ (Quick Start)

### 1) ตรวจสอบไฟล์ในโฟลเดอร์
โครงสร้างโฟลเดอร์มีดังนี้:
```
pet-ai-triage/
├── app.py              # ไฟล์ Backend Server และ Triage Logic
├── requirements.txt    # รายการแพ็กเกจ Python
├── .gitignore          # ป้องกันการเผลออัปโหลด API Key
├── README.md           # เอกสารโครงงานและคู่มือ
└── public/
    └── index.html      # หน้าเว็บ UI ระบบคัดกรองอาการ
```

### 2) ติดตั้ง Dependencies
เปิด Terminal หรือ Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วรัน:
```bash
pip install -r requirements.txt
```

### 3) รันโปรแกรม
```bash
python app.py
```
เมื่อรันสำเร็จ หน้าต่าง Terminal จะขึ้นข้อความ:
```
============================================================
  🐾 Pet AI Triage & First-Aid Assistant
  ระบบคัดกรองอาการและปฐมพยาบาลสัตว์เลี้ยงฉุกเฉินด้วย AI
============================================================
  🌐 เปิดเว็บเบราว์เซอร์แล้วเข้าไปที่:
     👉 http://localhost:8080
============================================================
```

### 4) เปิดใช้งานบนเว็บเบราว์เซอร์
เปิดเบราว์เซอร์ (Chrome, Edge หรือ Safari) แล้วเข้าไปที่:
👉 **`http://localhost:8080`**
